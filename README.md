# Личная CRM

Приложение для контактов людей, которых знаю лично: кто это, откуда знакомы, телефон, почта и заметки о разговорах. Идея и критерии успеха описаны в `specs/01-продуктовая-идея.md`.

## Что нужно на компьютере

- Node.js (LTS) и pnpm
- Docker Desktop — в нём работает база данных PostgreSQL

## Первый запуск

Все команды выполняются в папке проекта.

1. Запустите Docker Desktop и дождитесь, пока он загрузится.
2. Создайте файл `.env`: скопируйте `.env.example` и заполните значения. Если `.env` уже есть, пропустите этот шаг.
3. Установите зависимости:
   ```
   pnpm install
   ```
4. Запустите базу данных:
   ```
   pnpm db:up
   ```
5. Создайте таблицы в базе:
   ```
   pnpm db:migrate
   ```
6. Заполните базу тестовыми контактами (1000 штук). Скрипт сработает, только если база пустая:
   ```
   pnpm db:seed
   ```
7. Запустите приложение:
   ```
   pnpm dev
   ```
8. Откройте в браузере http://localhost:3000

## Обычный запуск

Если всё уже настроено:

1. Запустите Docker Desktop — база поднимется сама.
2. В папке проекта выполните `pnpm dev`.
3. Откройте http://localhost:3000

Чтобы остановить приложение, нажмите `Ctrl+C` в окне терминала, где оно запущено.

## Полезные команды

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | Запускает приложение в режиме разработки: изменения в коде видны сразу |
| `pnpm build` и `pnpm start` | Собирает и запускает приложение в «боевом» режиме: работает быстрее |
| `pnpm db:up` | Запускает базу данных в Docker |
| `pnpm db:generate` | Готовит миграцию после изменения схемы таблиц в `src/db/schema.ts` |
| `pnpm db:migrate` | Применяет миграции к базе |
| `pnpm db:seed` | Заполняет пустую базу тестовыми контактами |
| `pnpm lint` | Проверяет код на ошибки |

## Где что лежит

- `src/app` — страницы: список контактов (`page.tsx`), карточка контакта (`contacts/[id]`), новый контакт (`contacts/new`)
- `src/components` — части интерфейса: форма контакта, таблица, поиск
- `src/lib` — работа с контактами в базе и проверка полей формы
- `src/db` — схема таблиц, подключение к базе и скрипт тестовых данных
- `drizzle` — миграции базы данных
- `compose.yaml` — настройки PostgreSQL в Docker (порт 5433)
