# contact-groups Specification

## Purpose

Раскладывать контакты по своим группам (семья, друзья, теннис), чтобы быстро находить людей одного круга общения: группы видны в списке, по ним работают фильтр и поиск.

## Requirements

### Requirement: Группа контактов

Система SHALL позволять пользователю заводить группы контактов с любыми названиями. Название группы: обязательное, пробелы по краям отбрасываются, не больше 50 символов. Названия MUST быть уникальны без учёта регистра: «Теннис» и «теннис» - одна и та же группа. Контакт может входить в любое число групп, в том числе ни в одну. Группа без контактов остаётся.

#### Scenario: Контакт в нескольких группах
- **WHEN** пользователь отмечает у контакта группы «Друзья» и «Теннис» и нажимает «Сохранить»
- **THEN** после перезагрузки страницы в карточке отмечены обе группы

#### Scenario: Контакт без групп
- **WHEN** пользователь снимает все отметки групп у контакта и нажимает «Сохранить»
- **THEN** контакт сохраняется без групп, и в списке в колонке «Группы» у него пусто

#### Scenario: Группа без контактов
- **WHEN** пользователь создаёт группу «Аналитики» и ни одного контакта в неё не добавляет
- **THEN** группа есть на странице «Группы» с нулём контактов

### Requirement: Группы в карточке и форме нового контакта

Карточка контакта и форма нового контакта SHALL содержать поле «Группы»: список всех существующих групп с отметками и поле «Новая группа» с кнопкой «Добавить». Новая группа создаётся, сразу отмечается у этого контакта и появляется в списке для всех контактов. Если групп ещё нет, видна подсказка «Групп пока нет». Отметки сохраняются вместе с остальными полями кнопкой «Сохранить» или «Добавить контакт».

#### Scenario: Создать группу в карточке
- **WHEN** пользователь пишет в поле «Новая группа» «Аналитики», нажимает «Добавить», затем «Сохранить»
- **THEN** группа «Аналитики» отмечена у этого контакта и видна в списке групп в карточке любого другого контакта

#### Scenario: Группы при создании контакта
- **WHEN** пользователь создаёт контакт и отмечает группу «Семья»
- **THEN** в карточке нового контакта группа «Семья» отмечена

#### Scenario: Групп ещё нет
- **WHEN** в системе нет ни одной группы и пользователь открывает форму нового контакта
- **THEN** в поле «Группы» видна подсказка «Групп пока нет» и поле «Новая группа»

#### Scenario: Название уже есть
- **WHEN** группа «Теннис» существует, а пользователь пытается добавить «теннис»
- **THEN** новая группа не создаётся, существующая «Теннис» отмечается у контакта

#### Scenario: Пустое название
- **WHEN** пользователь нажимает «Добавить» в поле «Новая группа», ничего не написав или написав одни пробелы
- **THEN** группа не создаётся, под полем видна ошибка «Напишите название группы»

#### Scenario: Слишком длинное название
- **WHEN** пользователь вводит название из 51 символа и нажимает «Добавить»
- **THEN** группа не создаётся, под полем видна ошибка «Не больше 50 символов»

### Requirement: Страница «Группы»

Система SHALL иметь страницу «Группы» со ссылкой с главной страницы. Страница показывает все группы по алфавиту, у каждой название и число контактов. Здесь же можно создать группу, переименовать и удалить. Название группы - ссылка на список контактов, отфильтрованный по этой группе.

#### Scenario: Список групп
- **WHEN** есть группы «Друзья» с двумя контактами и «Теннис» с одним
- **THEN** на странице видно «Друзья - 2», «Теннис - 1», в алфавитном порядке

#### Scenario: Создать группу на странице
- **WHEN** пользователь пишет «Семья» в поле «Новая группа» на странице «Группы» и нажимает «Добавить»
- **THEN** «Семья» появляется в списке с нулём контактов

#### Scenario: Переход к контактам группы
- **WHEN** пользователь нажимает на название «Теннис» на странице «Группы»
- **THEN** открывается главная страница с отфильтрованными контактами группы «Теннис»

#### Scenario: Групп нет
- **WHEN** в системе нет групп
- **THEN** страница показывает «Групп пока нет» и поле «Новая группа»

### Requirement: Переименование группы

Система SHALL позволять переименовать группу на странице «Группы». К новому названию применяются те же правила, что и при создании. Контакты группы не меняются, новое название видно везде.

#### Scenario: Переименовать
- **WHEN** пользователь меняет «Теннис» на «Теннис по средам» и сохраняет
- **THEN** контакты прежней группы теперь в группе «Теннис по средам», в списке и карточках видно новое название

#### Scenario: Только регистр
- **WHEN** пользователь меняет «теннис» на «Теннис»
- **THEN** название сохраняется, ошибки о повторе нет

#### Scenario: Название занято другой группой
- **WHEN** группы «Друзья» и «Теннис» существуют, и пользователь переименовывает «Теннис» в «друзья»
- **THEN** переименование не проходит, видна ошибка «Группа с таким названием уже есть», название остаётся прежним

### Requirement: Удаление группы

Система SHALL позволять удалить группу на странице «Группы». Перед удалением система MUST спросить подтверждение, в вопросе названа группа и число её контактов. Удаление снимает группу со всех контактов; сами контакты, их заметки и остальные группы не меняются.

#### Scenario: Удалить группу
- **WHEN** пользователь удаляет группу «Теннис» с тремя контактами и подтверждает
- **THEN** группы нет на странице «Группы», все три контакта остались в списке, группы «Теннис» у них нет

#### Scenario: Отказаться от удаления
- **WHEN** пользователь нажимает «Удалить» у группы и отменяет в вопросе подтверждения
- **THEN** группа и её контакты остаются как были

#### Scenario: Другие группы контакта
- **WHEN** у контакта группы «Друзья» и «Теннис», и удаляют «Теннис»
- **THEN** у контакта остаётся только «Друзья»

### Requirement: Группы в общем списке контактов

Общий список контактов SHALL показывать колонку «Группы» с названиями всех групп контакта через запятую, по алфавиту; у контакта без групп ячейка пустая. На узком экране, где в списке помещаются только имена, колонка скрыта, как «Как часто», телефон и почта.

#### Scenario: Колонка в списке
- **WHEN** у одного контакта группы «Друзья» и «Теннис», у другого групп нет
- **THEN** в широком окне у первого в колонке «Группы» «Друзья, Теннис», у второго пусто

### Requirement: Фильтр списка по группе

Над списком контактов SHALL быть выбор группы с вариантами «Все группы» и по одному на каждую существующую группу. По умолчанию выбрано «Все группы». При выбранной группе в списке только её контакты. Выбранная группа хранится в адресе страницы, поэтому фильтр переживает перезагрузку и работает вместе с поиском: показаны контакты, подходящие и под группу, и под запрос. Счётчик над списком считает показанные контакты. Блок «Пора связаться» выбранной группой не фильтруется.

#### Scenario: Выбрать группу
- **WHEN** контакты Анна и Борис в группе «Теннис», Вера нет, и пользователь выбирает «Теннис»
- **THEN** в списке Анна и Борис, Веры нет

#### Scenario: Вернуть все
- **WHEN** выбрана группа «Теннис», и пользователь выбирает «Все группы»
- **THEN** в списке снова все контакты

#### Scenario: Фильтр вместе с поиском
- **WHEN** выбрана группа «Теннис» и в поиске написано «Ан»
- **THEN** в списке только контакты группы «Теннис», в имени или группах которых есть «Ан»

#### Scenario: Фильтр после перезагрузки
- **WHEN** выбрана группа «Теннис» и пользователь перезагружает страницу
- **THEN** группа «Теннис» по-прежнему выбрана, список отфильтрован

#### Scenario: Пустая группа
- **WHEN** пользователь выбирает группу, в которой нет контактов
- **THEN** вместо списка видно «В этой группе пока нет контактов»

#### Scenario: Группа удалена, пока открыт адрес с фильтром
- **WHEN** пользователь открывает адрес с фильтром по группе, которой уже нет
- **THEN** выбрано «Все группы», в списке все контакты

### Requirement: Поиск по названию группы

Строка поиска SHALL находить контакты и по имени, и по названию группы: контакт показывается, если запрос входит в его имя или в название любой из его групп, без учёта регистра. Подсказка в поле: «Поиск по имени или группе».

#### Scenario: Поиск по группе
- **WHEN** пользователь пишет в поиске «теннис», и в группе «Теннис» два контакта
- **THEN** эти два контакта в списке, даже если «теннис» нет в их именах

#### Scenario: Поиск по имени работает как раньше
- **WHEN** пользователь пишет в поиске «Анна», и ни в одной группе нет «анна» в названии
- **THEN** в списке контакты с «Анна» в имени

#### Scenario: Подсказка в поле
- **WHEN** пользователь открывает главную страницу
- **THEN** в пустом поле поиска виден текст «Поиск по имени или группе»
