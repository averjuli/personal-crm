## Workflow follow-up

- По отдельной просьбе пользовательницы: коммит, push, PR в main и сразу автовлитие через `gh pr merge --auto --squash`. Перед merge все проверки CI, включая сборку образа, должны быть зелёными.
- После merge проверить автоматическую выкатку на тест-стенд, пройти ручную проверку из README.md, переключиться на свежий main и удалить локальную ветку. При красном smoke сообщить, не откатывать автоматически.
- Выкатку на прод запускает пользовательница. Передать ей способ ручной проверки и отката через Deploy prod; новых обратных миграций не выполнять.
- Архивировать `birthdays` отдельным запросом после завершения реализации и необходимых проверок.
