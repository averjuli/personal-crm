# Spec Delta

## MODIFIED Requirements

### Requirement: Группа контактов

Система SHALL позволять пользователю заводить свои группы контактов с любыми названиями. Название группы: обязательное, пробелы по краям отбрасываются, не больше 50 символов. Названия MUST быть уникальны без учёта регистра среди групп одного пользователя: «Теннис» и «теннис» у одного пользователя - одна и та же группа, а у разных пользователей могут быть группы с одинаковыми названиями. Контакт может входить в любое число групп своего владельца, в том числе ни в одну. Группа без контактов остаётся.

#### Scenario: Контакт в нескольких группах
- **WHEN** пользователь отмечает у контакта группы «Друзья» и «Теннис» и нажимает «Сохранить»
- **THEN** после перезагрузки страницы в карточке отмечены обе группы

#### Scenario: Контакт без групп
- **WHEN** пользователь снимает все отметки групп у контакта и нажимает «Сохранить»
- **THEN** контакт сохраняется без групп, и в списке в колонке «Группы» у него пусто

#### Scenario: Группа без контактов
- **WHEN** пользователь создаёт группу «Аналитики» и ни одного контакта в неё не добавляет
- **THEN** группа есть на странице «Группы» с нулём контактов

#### Scenario: Одинаковые группы у разных пользователей
- **WHEN** у A есть группа «Друзья», и B создаёт группу «Друзья»
- **THEN** у B появляется своя группа «Друзья» с нулём контактов, группа A не меняется, и каждый видит только свою

### Requirement: Группы в карточке и форме нового контакта

Карточка контакта и форма нового контакта SHALL содержать поле «Группы»: список всех групп пользователя с отметками и поле «Новая группа» с кнопкой «Добавить». Новая группа создаётся, сразу отмечается у этого контакта и появляется в списке для всех контактов этого пользователя. Если у пользователя групп ещё нет, видна подсказка «Групп пока нет». Отметки сохраняются вместе с остальными полями кнопкой «Сохранить» или «Добавить контакт».

#### Scenario: Создать группу в карточке
- **WHEN** пользователь пишет в поле «Новая группа» «Аналитики», нажимает «Добавить», затем «Сохранить»
- **THEN** группа «Аналитики» отмечена у этого контакта и видна в списке групп в карточке любого другого его контакта

#### Scenario: Группы при создании контакта
- **WHEN** пользователь создаёт контакт и отмечает группу «Семья»
- **THEN** в карточке нового контакта группа «Семья» отмечена

#### Scenario: Групп ещё нет
- **WHEN** у пользователя нет ни одной группы и он открывает форму нового контакта
- **THEN** в поле «Группы» видна подсказка «Групп пока нет» и поле «Новая группа»

#### Scenario: Название уже есть
- **WHEN** у пользователя есть группа «Теннис», а он пытается добавить «теннис»
- **THEN** новая группа не создаётся, его существующая «Теннис» отмечается у контакта

#### Scenario: Такое название есть только у другого пользователя
- **WHEN** у A есть группа «Теннис», у B её нет, и B добавляет «теннис» в карточке своего контакта
- **THEN** у B создаётся своя группа «теннис» и отмечается у его контакта, группа A не меняется

#### Scenario: Пустое название
- **WHEN** пользователь нажимает «Добавить» в поле «Новая группа», ничего не написав или написав одни пробелы
- **THEN** группа не создаётся, под полем видна ошибка «Напишите название группы»

#### Scenario: Слишком длинное название
- **WHEN** пользователь вводит название из 51 символа и нажимает «Добавить»
- **THEN** группа не создаётся, под полем видна ошибка «Не больше 50 символов»

### Requirement: Страница «Группы»

Система SHALL иметь страницу «Группы» со ссылкой с главной страницы. Страница показывает все группы пользователя по алфавиту, у каждой название и число её контактов. Здесь же можно создать группу, переименовать и удалить. Название группы - ссылка на список контактов, отфильтрованный по этой группе.

#### Scenario: Список групп
- **WHEN** есть группы «Друзья» с двумя контактами и «Теннис» с одним
- **THEN** на странице видно «Друзья - 2», «Теннис - 1», в алфавитном порядке

#### Scenario: Создать группу на странице
- **WHEN** пользователь пишет «Семья» в поле «Новая группа» на странице «Группы» и нажимает «Добавить»
- **THEN** «Семья» появляется в списке с нулём контактов

#### Scenario: Переход к контактам группы
- **WHEN** пользователь нажимает на название «Теннис» на странице «Группы»
- **THEN** открывается главная страница с отфильтрованными контактами группы «Теннис»

#### Scenario: Групп нет
- **WHEN** у пользователя нет групп
- **THEN** страница показывает «Групп пока нет» и поле «Новая группа»

### Requirement: Переименование группы

Система SHALL позволять переименовать группу на странице «Группы». К новому названию применяются те же правила, что и при создании. Контакты группы не меняются, новое название видно везде.

#### Scenario: Переименовать
- **WHEN** пользователь меняет «Теннис» на «Теннис по средам» и сохраняет
- **THEN** контакты прежней группы теперь в группе «Теннис по средам», в списке и карточках видно новое название

#### Scenario: Только регистр
- **WHEN** пользователь меняет «теннис» на «Теннис»
- **THEN** название сохраняется, ошибки о повторе нет

#### Scenario: Название занято другой группой
- **WHEN** у пользователя есть группы «Друзья» и «Теннис», и он переименовывает «Теннис» в «друзья»
- **THEN** переименование не проходит, видна ошибка «Группа с таким названием уже есть», название остаётся прежним

#### Scenario: Название есть только у другого пользователя
- **WHEN** у A есть группа «Друзья», а B переименовывает свою группу «Теннис» в «Друзья»
- **THEN** переименование проходит, у B группа называется «Друзья», группа A не меняется

### Requirement: Фильтр списка по группе

Над списком контактов SHALL быть выбор группы с вариантами «Все группы» и по одному на каждую группу пользователя. По умолчанию выбрано «Все группы». При выбранной группе в списке только её контакты. Выбранная группа хранится в адресе страницы, поэтому фильтр переживает перезагрузку и работает вместе с поиском: показаны контакты, подходящие и под группу, и под запрос. Счётчик над списком считает показанные контакты. Блок «Пора связаться» выбранной группой не фильтруется.

#### Scenario: Выбрать группу
- **WHEN** контакты Анна и Борис в группе «Теннис», Вера нет, и пользователь выбирает «Теннис»
- **THEN** в списке Анна и Борис, Веры нет

#### Scenario: Вернуть все
- **WHEN** выбрана группа «Теннис», и пользователь выбирает «Все группы»
- **THEN** в списке снова все контакты

#### Scenario: Фильтр вместе с поиском
- **WHEN** выбрана группа «Теннис» и в поиске написано «Ан»
- **THEN** в списке только контакты группы «Теннис», в имени или группах которых есть «Ан»

#### Scenario: Фильтр после перезагрузки
- **WHEN** выбрана группа «Теннис» и пользователь перезагружает страницу
- **THEN** группа «Теннис» по-прежнему выбрана, список отфильтрован

#### Scenario: Пустая группа
- **WHEN** пользователь выбирает группу, в которой нет контактов
- **THEN** вместо списка видно «В этой группе пока нет контактов»

#### Scenario: Группа удалена, пока открыт адрес с фильтром
- **WHEN** пользователь открывает адрес с фильтром по группе, которой уже нет
- **THEN** выбрано «Все группы», в списке все контакты
